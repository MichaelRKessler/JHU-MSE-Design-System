Brand statistics format: big Roboto Slab number + label, optional rule-separated description and icon.

Provide `value` (the number, set in Roboto Slab) and `label`, optionally `description` (longer copy beside a 1px vertical rule), `icon` and `onDark` for Heritage Blue backgrounds. This is the brand's documented statistics format; one idea per block.

```jsx
<StatBlock value="#1" label="in U.S. research spending" description="More than any other U.S. academic institution, 40+ years running." />
```
