Underline tabs; gold indicator on the active tab.

Provide `tabs` (labels) and optionally `active` and `onChange` for a controlled tab set; omit `active` for uncontrolled. Underline tabs with a Gold indicator on the active tab. The consumer renders the panel content.

```jsx
<Tabs tabs={['Undergraduate', 'Graduate', 'PhD']} onChange={setTab} />
```
