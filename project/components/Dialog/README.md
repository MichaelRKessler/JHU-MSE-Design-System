Modal over a Heritage Blue scrim, top brand bar.

Provide `open`, `title`, `children`, `onClose` and optionally `footer` (an action row of Buttons, Cancel first) and `width` (default 480). Renders a fixed Heritage Blue scrim; clicking the scrim closes it.

```jsx
<Dialog open={open} title="Request information" onClose={close} footer={<Button>Submit</Button>}>…</Dialog>
```
