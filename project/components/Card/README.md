Square-cornered editorial card: optional 3:2 image, condensed eyebrow, Heritage Blue title, arrow CTA. Hover raises the shadow.

Provide `title` and `children` (body copy, 1 to 3 sentences), and optionally `eyebrow` (condensed all-caps label), `image` (URL or node, cropped 3:2, never rounded), `accent` (`top` for a Heritage Blue bar, `gold` for a Gold bar) and `cta` with `onCtaClick`. The container sets the width; cards stretch to equal height in a grid.

```jsx
<Card accent="top" eyebrow="Research" title="Biomaterials" cta="Learn more">Engineering materials that interface with living systems.</Card>
```
