Square icon-only button.

Provide `icon` (a node: a Font Awesome `<i>` on the web, which needs the Font Awesome 6.5.2 stylesheet loaded by the consumer, or an `<img>` of an official JHU icon) and `label` (used as `aria-label` and tooltip). `primary` is a Heritage Blue square; `subtle` is bordered on white. `size` sets the square in px (default 40).

```jsx
<IconButton icon={<i className="fa-solid fa-magnifying-glass" />} label="Search" />
```
Variants: primary (Heritage Blue fill), subtle (bordered).
